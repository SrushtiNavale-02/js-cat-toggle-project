# 🐱 Cat Light Switch Mini Project

An interactive web application demonstrating DOM manipulation with an ON/OFF cat and bulb switch.

## 🔗 Live Demo
Check out the live project here: [Cat Light Switch Demo](https://srushtinavale-02.github.io/js-cat-toggle-project/)

## 🛠️ Built With
* **HTML5**
* **CSS3**
* **Bootstrap 4.5.2**
* **Vanilla JavaScript**

## ✨ Features
* Interactive ON / OFF toggle buttons
* Dynamic image switching (Light bulb and Cat)
* Live DOM style and text updates
